# secondplan

Программа для удаленного завершения работы Windows-компьютера через Telegram-бота. Написана на Python с использованием библиотеки aiogram. Код оптимизирован для работы напрямую с переменными окружения.

## Особенности
- Ограничение доступа: Бот выполняет команды только от пользователя, чей ID указан в настройках.
- Удобная авторизация: При попытке доступа стороннего пользователя бот выводит его Telegram ID в формате, доступном для копирования в один клик.
- Минималистичная структура: Проект работает без файла config.py, настройки считываются напрямую из .env.

## Инструкция по установке и запуску

### 1. Получение данных от Telegram
1. Откройте Telegram и найдите официального бота @BotFather.
2. Создайте нового бота с помощью команды /newbot и скопируйте выданный API Token.
3. Узнайте свой Telegram ID. Для этого можно запустить созданного бота и отправить команду /start — бот выведет ваш ID на экран.

### 2. Настройка конфигурации
Откройте файл `.env` в корневой папке проекта и заполните его:

```text
# Твой айди сюда (только цифры)
ADMIN_ID="ВАШ_TELEGRAM_ID"

# Botfather тебе выдал сюда, опять между кавычек
BOT_TOKEN="ВАШ_ТОКЕН_БОТА"
```

### 3. Запуск на Windows
Откройте командную строку или PowerShell в папке проекта и выполните следующие команды:

```bash
# Установка необходимых библиотек
pip install -r requirements.txt

# Запуск бота
python main.py
```

После запуска бот готов к приему команды /shutdown для выключения ПК.
